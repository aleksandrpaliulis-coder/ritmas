# Paros ritmas

Veikia be rysio, duomenys laikomi pacio telefono narsykleje ir niekur nesiunciami.

Kodo saltinis ir dokumentacija: asmeniniame aplanke `projects/ritmas`.
Sitas repozitoriumas yra tik sugeneruota pakuote, skirta GitHub Pages.
